# The Flovr brand

The mark is three waves, the older ones fainter: a flow, and the versions it went through.

| File | For |
|---|---|
| `mark.svg` | The mark on its lime square, on dark grounds and as the favicon |
| `mark-light.svg` | The mark on a darker green, on light grounds |
| `logo-dark.png`, `logo-light.png` | The mark with the name, for dark and light pages |
| `avatar.png` | The avatar of the flovrlabs organization, 1000×1000 |
| `social-preview.png` | The picture a link to the repository shows, 1280×640 |

The name is written **flovr** in the logo and Flovr in text, and said *flow-ver*. It is set in [Geist](https://vercel.com/font) at weight 600, 4.5% tighter than normal.

| Colour | Dark ground | Light ground |
|---|---|---|
| Ground | `#0c0d0a` | `#f6f7f2` |
| Text | `#f1f3ea` | `#16180f` |
| Lime | `#a3e635`, with `#1a2e05` on it | `#4d7c0f`, with white on it |

Each kind of step keeps its colour in both: trigger `#ea580c`, decide `#7c3aed`, ai `#059669`, http `#0284c7`.
